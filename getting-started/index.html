观澜 Velora

让理解成为下一次学习的起点

在自己的电脑上，和 Agent 一起把提供的材料整理成可以持续编辑的学习文档。

阅读这里，创作在本地

这个网站是公开学习文档的只读版本。本地工作台支持对话、直接编辑、段落修改、历史和导出。文档保存在自己的文件夹中，Agent 的回答使用你配置的本机模型服务。

下载并安装

准备 Node.js 22.12+ 或 24 与 npm。下载后，在安装包所在的目录打开终端，执行以下命令。安装依赖需要联网。

下载 v0.1.0 安装包 ↓

mkdir velora-local
cd velora-local
npm init -y
npm install ../agent-learning-workbench-0.1.0.tgz
mkdir notes
npx --no-install learn-workbench --root ./notes init --title "我的学习空间"
npx --no-install learn-workbench --root ./notes serve

打开 http://127.0.0.1:4178 即可使用。下次回到 velora-local 目录，重新执行最后一条命令就能继续。

第一次使用 Agent 前，请安装并登录本机的 Codex 或 Claude Code，然后在工作台的本地设置中选择。没有可用 Agent 时，仍能阅读、手工编辑和导出。

核对安装包

文件名：agent-learning-workbench-0.1.0.tgz
版本：0.1.0
SHA-256：

44dfbe293acb05cd1f45ab26c46882062221195cc595f4edd8926decc101cbcd

下载校验值文件。这份安装包包含编译后的本地界面、CLI、SDK、MCP 与源码，按项目 MIT 许可分发。

开始第一篇学习文档

  1. 打开或新建一个学习空间，把已有材料整理到学习文档中。
  2. 提出具体问题，请 Agent 结合提供的资料解释并写入文档。
  3. 阅读保存结果，加入自己的例子，选中段落继续追问或修改。

Agent 只访问工作台提供的学习文档和受控工具。打开文件夹不等于已经读取里面的源码。Codex 支持逐段实时编辑；Claude 生成修改后由工作台保存。

导出与备份

Markdown 导出适合分享已保存的正文。恢复整个工作台还需要保存 manifest、配置以及 .learn/ 中的协作状态和历史。公开发布前，选择并审阅要公开的篇目。
